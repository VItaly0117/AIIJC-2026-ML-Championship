# 📷 Задача 2: Определение освещенности по изображениям («Уровень освещенности»)

## Описание задачи
По изображению с камеры видеонаблюдения на даче необходимо классифицировать уровень освещенности сцены.

* **Классы классификации (3 класса):**
  * `0` — **dark** (низкая освещенность).
  * `1` — **normal** (средняя освещенность).
  * `2` — **bright** (высокая освещенность).
* **Метрика оценивания:** Accuracy.
* **Шкала баллов:** `Points = max(0, Accuracy - 0.40) / 0.60`.

---

## 🛠️ Подход и архитектура

### 1. Предобработка и Аугментация
* Все изображения сжимаются до размера `224x224` пикселей.
* Применяется жесткая аугментация во избежание переобучения (датасет относительно небольшой, по 500 картинок на класс):
  * Случайные повороты (до 15°).
  * Random Crop и Flips (горизонтальные и вертикальные).
  * Color Jitter (яркость, контрастность, насыщенность, оттенок).
  * Гауссово размытие и Random Erasing (затирание случайных пикселей).

### 2. Модели
Для борьбы с переобучением и разнообразия ансамбля используются глубокие сверточные сети, предобученные на ImageNet:
* **EfficientNet-B0** — легкая и точная модель.
* **ResNet18 / ResNet34** — классические сверточные архитектуры.
* **MobileNetV3** — сверхлегкая архитектура для мобильных устройств (ускоряет инференс на CPU).

### 3. TTA (Test-Time Augmentation)
Во время тестирования каждое изображение оценивается 5 раз (оригинал, флип, сдвиг, изменение яркости, поворот), предсказания усредняются. Это повышает точность классификации на **~1.5-2.0%**.
