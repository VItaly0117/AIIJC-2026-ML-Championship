# 📈 Задача 1: Предсказание повторного обращения пользователя («Я вернусь позже»)

## Описание задачи
По агрегированным признакам активности пользователя необходимо предсказать, вернётся ли он в мобильное приложение в ближайший период.

* **Целевая переменная (`retention`):**
  * `1` — пользователь вернётся.
  * `0` — пользователь не вернётся.
* **Метрика оценивания:** ROC-AUC.
* **Шкала баллов:** `Points = max(0, ROC-AUC - 0.60) / 0.40`.

---

## 🛠️ Подход и архитектура

### 1. Feature Engineering (8 ➔ 89 признаков)
Мы провели глубокий анализ поведения пользователей и сгенерировали новые фичи:
* **RFM метрики:** Recency (свежесть), Frequency (частота сессий + покупок), Monetary (суммарные траты).
* **Соотношения и средние:** покупки на день активности, средний чек на сессию, среднее время сессии.
* **Метрики стабильности:** коэффициент вариации длительности сессий, стабильность сессий.
* **Полиномиальные и нелинейные признаки:** квадраты и кубы ключевых числовых показателей.
* **Тригонометрические признаки:** синусы/косинусы для учета цикличности использования приложения.

### 2. Модели и Настройка (Optuna)
Были оптимизированы и обучены 4 типа моделей на 10-фолдовой кросс-валидации (Stratified K-Fold) с 5 различными случайными сидами (всего 200 моделей):
* **LightGBM** (CV ROC-AUC: `0.68519`)
* **CatBoost** (CV ROC-AUC: `0.68609`)
* **XGBoost** (CV ROC-AUC: `0.68232`)
* **Logistic Regression** (CV ROC-AUC: `0.63827`)

### 3. Блендинг и Стекинг
Для финального прогноза использовался **Probability Blend** (взвешенное усреднение предсказаний):
* `retention_pred = 0.45 * LGB + 0.05 * XGB + 0.475 * CAT + 0.025 * LR`
* Финальный OOF ROC-AUC: **0.68731** (дает **0.21827 Points** на лидерборде, выводя решение на **#1 место**).

## 🚀 Инструкция по запуску

1. Убедитесь, что файлы данных `train.csv`, `test.csv` и `sample_submission.csv` находятся в папке `data/`.
2. Запустите финальный скрипт:
   ```bash
   python solution_v3.py
   ```
3. Скрипт проведет кросс-валидацию, выведет метрики для каждой модели и сгенерирует файлы сабмитов в корневой папке.
