# ❄️ Задача 3: Классификатор погодных условий («За окном шумно»)

## Описание задачи
По изображению сцены с камеры беспилотного автомобиля необходимо определить погодное состояние. Изображения содержат погодные шумы (дождь, снег, туман) и искажения, затрудняющие классификацию.

* **Классы классификации (3 класса):**
  * `0` — **rain** (дождь).
  * `1` — **fog** (туман).
  * `2` — **snow** (снег).
* **Метрика оценивания:** Macro F1-score.
* **Шкала баллов:** `Points = max(0, F1 - 0.50) / 0.50`.

---

## 🛠️ Подход и архитектура

### 1. Архитектура модели
* Используется глубокая сверточная нейросеть **ResNet34**, предобученная на ImageNet.
* Применяется регуляризация (Weight Decay = 1e-4) и частичная заморозка слоев backbone для предотвращения переобучения на шумных данных.

### 2. Балансировка и оптимизация
* **WeightedRandomSampler** используется в DataLoader для устранения дисбаланса классов в тренировочной выборке.
* Обучение проводится с функцией потерь **CrossEntropyLoss** с применением **Label Smoothing (0.1)**.
* Для изменения темпа обучения (Learning Rate) используется планировщик **CosineAnnealingLR**.
